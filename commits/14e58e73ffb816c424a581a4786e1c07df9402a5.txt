borrowed from emulator terminology where it means the emulated *machine*;
here it named the *program*, so it duplicated the machine/port axis and
leaked into names that were never about code (`guest_x`, `guest_scale`,
`guest_picture`, `the live guest`).

the glossary, D144 and the ticket archive fails the gate, and so does a
tracked path that still carries it.
