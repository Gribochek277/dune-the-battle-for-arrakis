docs: the glyph table is not ASCII -- there is no lowercase, only Cyrillic
A finding the owner's eye produced and no check of mine did, so it goes on a page
where the next person writing a port screen will meet it before they ship it.

The encoding $6480 | the character invites the assumption that the glyph table is
the ASCII table. The 32 tiles reserved for a..z are Cyrillic, measured at $057DB6.
Which means every string the game displays is uppercase not by style but by
impossibility, and a port that prints a lowercase string draws Cyrillic silently --
the renderer draws exactly the tiles it is told to, the plane holds exactly the codes
it is given, and nothing fails.
