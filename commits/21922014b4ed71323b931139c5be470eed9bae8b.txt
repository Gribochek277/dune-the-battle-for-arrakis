message:
the window takes Vulkan as a widescreen renderer: the seam says which renderers take a layout
app/play_presenter.c decided whether a renderer is a v2 one (takes the
widescreen shell's layout) by name, and its Vulkan case sat behind
MDP_HAVE_VK, which the build defines for run_play.c alone. So the window never
recognised Vulkan: `--renderer vk` with `--fullscreen`, `--aspect` or any
shell flag was refused as 'not the v2 path' (the run-play review saw it as
test_scene_vk's 16:9 run being refused).

md_renderer_takes_layout() is the seam's answer -- the scene renderer, the GL
backend, or a backend that registered a layout hook (Vulkan does) -- and the
presenter asks it, with no build flag. `--renderer vk --fullscreen` now opens
at the display's 2560x1440.
