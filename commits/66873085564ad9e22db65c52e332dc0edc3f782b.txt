  analysis/*.txt stays ignored.

  from its branch, and a re-run in a clean worktree leaves `git status` empty.

  still linked, because it is regenerable or large.
* The audit of the pipeline's inputs is in docs/disassembly.md ("Pipeline
  inputs: what is committed and what is generated"): every input is tracked or
  generated by a named command that reproduces it, with the untracked ones
  split into required (dump, inventory, carrier, assets) and optional (coverage
  logs, cached reference captures, the work-RAM map, build scratch).
* tests/test_pipeline_inputs.py checks every row against the tree -- tracked
  files are in git ls-files, are not symlinks in the index or the worktree, are
  not matched by .gitignore and exist; generated ones are untracked, ignored

  fails the gate on ten negative controls (an untracked hand-written file, one

  file again). It is wired into tests/run_all.sh.
