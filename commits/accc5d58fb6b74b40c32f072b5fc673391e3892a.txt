ticket 149: the pointer is a key of the settings file
PORT SETTINGS' POINTER row held its value for the run and nothing wrote it down
(D53), so a player who chose SYSTEM got the port's arrow again on the next
start. The value is now the fifth key of display.ini -- `pointer = port-arrow |
system`, the screen's own two words in the file's lower-case style -- and the
file's load, save, format block and header comment know it. The row's handler
saves after it applies the value, the way a display row does; the load is the
display values' load, before the window opens, and the front end applies it to
the window's cursor and the overlay's arrow before the first frame (the path the
default already used). A file the old build wrote still loads with the default,
a bad line is refused with its number, and `the pointer:` is now printed at
start-up for every run, so a log says which pointer the run has.
