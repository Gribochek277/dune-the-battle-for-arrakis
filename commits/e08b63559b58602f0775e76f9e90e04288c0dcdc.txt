  process's CPU time on a POSIX host but the wall clock in milliseconds on

  reads the performance counter now; the check warms the core up for a third
  of a second first, and the three table sizes are measured in turn five times
  over, each keeping its fastest, so a drifting host moves them together.
  Five runs in a row: 99-113% (the bound is 125%), and the linear-scan control
  617-684%, still refused.

  build it has just run; Windows can hold an executable that just exited for a
  moment, so the copy is retried for up to five seconds (the first copy is
  the only one elsewhere).
