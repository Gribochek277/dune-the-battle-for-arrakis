segmentation: assert the split is disjoint, and prune orphaned sources
The generated sources carried duplicate instruction addresses (39 707 unique of
59 995 seen). The splitter's intervals were disjoint: the duplicates came from
files an earlier split had left in disassembly/out/asm/m68k, which sega2asm
never deletes. They are not assembled, but scripts/transpile68k.py reads the
whole directory and saw the same address twice, which inflated every count
taken from the prototype.

* make_segments.py asserts the merged intervals are sorted and non-overlapping,
  naming the offending pair, and reports a bad tiling explicitly instead of
  asserting the total; the candidate file is validated for reversed, empty,
  out-of-body and overlapping regions;
* --prune-dir deletes generated files whose segment left the split, and
  regenerate.sh passes the two output directories on every run;
* transpile68k.py prints the duplicate count unconditionally and exits non-zero
  when it is not zero, so no measurement silently runs on inflated input;
* tests/test_segment_split.py, run by tests/run_all.sh, re-checks the committed
  artifacts: the config tiles the body exactly, src/segments.inc matches it,
  there is exactly one generated file per code segment, no instruction address
  repeats, and the splitter refuses overlapping intervals.
